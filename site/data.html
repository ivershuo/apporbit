What the dataset includes

Rankings
Ordered app charts with market, store, category, and observation time.
Update history
The outcome of each chart update, including retries and reported errors.
App metadata
Names, developers, identifiers, icons, store links, descriptions, categories, prices, ratings, review totals, install ranges, monetization, content ratings, release dates, versions, system requirements, file sizes, languages, and update dates when a store provides them.
Movement
Previous rank, gains, losses, new entries, and longer-term trends.
