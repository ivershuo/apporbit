FOR AI AGENTS

Explore AppOrbit with your agent.

Install the AppOrbit skill to ask an AI agent about published App Store and Google Play rankings, changes, app details, and market coverage.

Install the skill

Node.js 22.12+ · HTTPS to GitHub

Run this command in a terminal. Choose your AI agent and installation scope if prompted.

npx skills add ivershuo/apporbit --skill apporbit

To target one agent, add -a codex as an example and replace codex with its agent ID. Add -g to install globally. See the supported agent IDs and AppOrbit skill listing.

Ask about rankings and movement

Start a new conversation with your agent and ask a question in natural language. The skill can find observed charts, compare complete snapshots, and link the exact sources.

“Show the latest observed top 10 free apps in the US App Store, with capture times and source links.”

“Which apps climbed most in the US Google Play free chart between the last two complete observations?”

Understand the answer

The skill reads ranking records from AppOrbit’s public GitHub data branch and may use website metadata for app names and details. It also reports available market coverage and app matches.

“Which markets have published ranking history?”

“Find this app and show its latest observed details.”
